# Churn_Analysis
End-to-end customer churn analysis using SQLite, Pandas, and Matplotlib—featuring cohort churn rates, ARPU, revenue-at-risk, and customer support escalation driver.Subscription churn diagnostics and retention modeling. Analyzed user lifecycles, calculated critical SaaS metrics (28.57% Churn, 73.94K Revenue at Risk), and isolated key churn drivers.
